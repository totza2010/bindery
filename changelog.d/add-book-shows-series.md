### Added
- **Add Book now shows which series a result belongs to, and whether you already have that series** — Hardcover reports the series and the book's place in it, but nothing downstream ever showed it, so choosing between two results meant adding one and looking at what appeared. A result that belongs to a series now reads `#5 Harry Potter`, ticked and highlighted when the library already holds that series, so a book that continues a series you are collecting is distinguishable at a glance from one that starts something new. The library is checked on the server against both the series' own provider ID and any Hardcover link added by hand, so a series you created yourself and linked afterwards counts as held. Results from OpenLibrary, Google Books and DNB carry no series label, because those providers do not report one; nor do standalone books. If the library cannot be read the results still arrive, simply without the mark.
